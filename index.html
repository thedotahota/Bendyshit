Bendmarks

Bend marks and cut length for tube with 90° bends. All lengths in mm.

Pipe

Axis and length, like y200 (add − for the other direction). Two values on one axis, like x 490 x 45, mean from x=490 to x=45.

Drawing

Green dot is the tube start (origin), red dot is the end, numbered circles are the bends.

Deduction table for this user (mm per bend)

New calculations use these values. Saved pipes keep the deduction they were saved with.

Data file

All users, their pipes and deduction tables are stored in this browser. Export this user saves one person's pipes and deduction table as their own JSON file (bendmarks-name.json). Export all users saves everyone in one file. Import loads either kind, for example on another phone or computer.
